Приложение для записи цен на OZON

Структура:
run.sh - скрипт для запуска под git bash
run.bat - скрипт для запуска под консоль Windows
set_ozon_pvz.bat - скрипт для выбора и сохранения ПВЗ/региона Ozon на Windows
set_ozon_pvz.sh - скрипт для выбора и сохранения ПВЗ/региона Ozon в bash
SKU_Ozon.txt - артикулы для проверки
reports - папка для сохранения отчётов
app - техническая папка

Первичная настройка ПВЗ/региона:
1) Запустить set_ozon_pvz.bat или set_ozon_pvz.sh.
2) В открывшемся окне Ozon выбрать нужный город/ПВЗ, например Москву.
3) Дождаться, пока выбранный адрес отобразится на сайте.
4) Вернуться в консоль и нажать ENTER.
5) В корне проекта появится файл ozon_session.json. Он хранит локальную сессию Ozon и не должен загружаться в Git.

Порядок работы:
1) Занести артикулы для проверки в файл SKU_Ozon.txt.
2) Убедиться, что файл ozon_session.json создан после выбора нужного ПВЗ.
3) Нажать два раза на один из скриптов run.bat или run.sh.
4) Дождаться выгрузки, в консоли будут сообщения о стадиях загрузки.
5) После завершения выгрузки нажать ENTER или закрыть консоль, отчёт будет лежать в папке reports.

Если нужно изменить ПВЗ/регион:
1) Снова запустить set_ozon_pvz.bat или set_ozon_pvz.sh.
2) Выбрать новый ПВЗ на сайте Ozon.
3) Нажать ENTER в консоли, чтобы перезаписать ozon_session.json.

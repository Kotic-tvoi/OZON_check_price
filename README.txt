Приложения для записи цен на OZON

Структура:
run.sh - скрипт для запуска под git bash
run.bat - скрипт для запуска под консоль windows
SKU_Ozon.txt - артикулы для проверки
reports - папка для сохранения отчётов
app - техническая папка

Порядок работы:
1) Занести артикулы для проверки в файл SKU_Ozon.txt
2) Нажать два раза на один из скриптов run.bat или run.sh
3) Дождаться выгрузки, в коносли будут сообщения о стадиях загрузки
4) После завершения выгрузки нажать ENTER или закрыть консоль, отчёт будет лежать в папке reports

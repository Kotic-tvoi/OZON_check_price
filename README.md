# Ozon — сбор цен со страницы магазина

Парсер только **читает** цены из основного каталога продавца Ozon (`#contentScrollPaginator`). Не открывает товарные карточки, не собирает рекомендации «Возможно, вам понравится», не изменяет цены и не использует базу данных. Каждый запуск открывает один Chrome, выбирает один ПВЗ, прокручивает каталог, накапливает уникальные артикулы и закрывает браузер.

## Локальный запуск

```bash
python -m pip install -r app/requirements.txt
python app/main.py --headed
```

По умолчанию: магазин `https://www.ozon.ru/seller/jkeratin/` и ПВЗ `https://www.ozon.ru/geo/moskva/442329/`. Для другого магазина или ПВЗ:

```bash
python app/main.py --headed --store "https://www.ozon.ru/seller/ДРУГОЙ_МАГАЗИН/" --pvz "https://www.ozon.ru/geo/ГОРОД/ID/"
```

Для дополнительной выгрузки JSON укажите `--json prices.json`. Без этого ключа цены выводятся в терминал и не сохраняются на диск. При медленной загрузке можно указать `--load-timeout 4 --idle-limit 5`.

В консоли выводится `конец каталога подтверждён: True/False`. Если False, скрипт получил некоторые цены, но не может гарантировать полноту каталога. Не трактуйте отсутствующий артикул как отсутствующий товар.

## HTTP API и Google Таблицы (после локальной проверки)

```bash
export OZON_API_TOKEN='your-long-random-secret'
python app/server.py
```

`POST /v1/catalog` с телом `{"store_url":"https://www.ozon.ru/seller/jkeratin/","pvz_url":"https://www.ozon.ru/geo/moskva/442329/"}` возвращает весь каталог. `POST /v1/prices` дополнительно принимает `"articles":["380181277"]` и возвращает только указанные артикулы в исходном порядке. Дополнительный `POST /v1/prices.xlsx` возвращает Excel с двумя колонками. Токен передаётся в `Authorization: Bearer ...`. `GET /health` служит для проверки доступности сервиса.

При неподтверждённой полноте каталога API возвращает ошибку 503 и **не заполняет таблицу неполными данными**. Google Apps Script: `google_sheets/Code.gs`; колонка A — артикулы, B — цены, H2 — ссылка ПВЗ, H4 — ссылка магазина. Для вызова из Apps Script требуется HTTPS-прокси. Google Таблица обновляется за один запрос; частичные результаты не записываются.

## Оговорки

- Цены берутся из видимых карточек каталога магазина. Выбранный ПВЗ подтверждается по шапке страницы.
- Окончание каталога определяется по границе каталога и отсутствию новых SKU в нескольких циклах ожидания; это эвристика Ozon. Сайт может изменить разметку или подгрузку.
- При CAPTCHA парсер может один раз перезапустить браузер, но не решает CAPTCHA автоматически.
- Для следующего локального теста предоставьте ссылку на другой магазин и ссылку на новый ПВЗ.

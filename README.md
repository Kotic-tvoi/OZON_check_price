# OzonPrices — проверка цен Ozon

Локальное приложение Windows с полями для магазина и ПВЗ. Сотрудник нажимает «Проверить цены и отправить», программа открывает Chrome, собирает цены, по желанию сохраняет Excel и записывает их в Google Таблицу.

## Установка и запуск на Windows

1. Скачать проект, распаковать в папку, которую не планируется перемещать.
2. Дважды нажать **УСТАНОВКА.bat** (один раз). Файл создаёт `.venv` и устанавливает библиотеки только внутрь него; глобальные библиотеки не изменяются.
3. Дважды нажать **ЗАПУСК.bat** для запуска программы.
4. Ввести ссылки магазина/ПВЗ или оставить пустыми. Нажать кнопку. В окне отображается ход сбора и результат.

Файлы `service-account.json` и `config.local.json` необходимы для текущего подключения Google API.

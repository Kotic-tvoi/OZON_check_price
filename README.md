# OzonPrices — проверка цен Ozon

Локальная программа Windows для проверки конечных цен Ozon. Пользователь при необходимости указывает магазин и ПВЗ и нажимает «Проверить цены и отправить». Программа открывает Chrome, собирает цены, по желанию сохраняет Excel и передаёт результаты в Google Таблицу.

## Запуск на Windows

1. Скачать проект и распаковать в постоянную папку.
2. **Дважды нажать `ЗАПУСК.bat`.
4. Ввести ссылки магазина и ПВЗ или оставить поля пустыми: по умолчанию используются магазин JKeratin и московский ПВЗ.
5. Нажать кнопку. Программа покажет итоговое сообщение «Готово. Выгружены цены N товаров».

Для подключения Google API рядом с `ЗАПУСК.bat` необходимы `service-account.json` и `config.local.json`. Это закрытые файлы администратора. **Не загружайте их в GitHub и не распространяйте JSON-ключ публично.**

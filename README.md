# Ozon — сбор цен из каталога магазина

Программа читает цены **всех товаров** из основного каталога продавца Ozon (`#contentScrollPaginator`). Никаких списков SKU передавать не нужно. Отдельные карточки товаров не открываются; блок рекомендаций «Возможно, вам понравится» исключается. История цен и Excel на диск автоматически не записываются.

## Локальный запуск

```bash
python -m pip install -r app/requirements.txt
python app/main.py --headed
```

По умолчанию открываются JKeratin и московский ПВЗ из `app/config.py`. Для другого магазина и ПВЗ:

```bash
python app/main.py --headed \
  --store "https://www.ozon.ru/seller/another-seller/" \
  --pvz "https://www.ozon.ru/geo/moskva/442329/"
```

Локальный запуск выводит все найденные артикулы и цены **в терминал**. При необходимости `--json prices.json` явно сохраняет JSON-файл. Параметр `--xlsx` убран: Excel не сохраняется на диск при обычном запуске.

## Настройки: `app/config.py`

- `LOAD_TIMEOUT = 1.5` — максимальное ожидание новой порции карточек после прокрутки.
- `SCROLL_POLL_INTERVAL = 0.1` — интервал проверки появления новых товаров.
- `PVZ_READY_TIMEOUT = 4.0` — ожидание адреса и кнопки сохранения ПВЗ.
- `STORE_READY_TIMEOUT = 5.0` — ожидание каталога магазина и подтверждённого ПВЗ.
- `CAPTCHA_MAX_ATTEMPTS = 2` — число запусков браузера всего, включая первый.

Остальные параметры подробно описаны комментариями непосредственно в `config.py`.
Временные ограничения — **максимумы**, а не обязательные паузы. Если страница готова раньше, программа продолжает сразу. Скорость прокрутки можно менять через `--load-timeout`, `--idle-limit` и `--max-scrolls`.

## HTTP API (для будущего развёртывания)

```bash
export OZON_API_TOKEN='your-long-random-secret'
python app/server.py
```

- `GET /health` — готовность сервера.
- `POST /v1/catalog` — весь каталог в JSON.
- `POST /v1/catalog.xlsx` — тот же каталог в Excel **из памяти**, без записи на диск сервера.

Для обоих POST запросов отправляйте необязательные `store_url` и `pvz_url`; при их отсутствии используются значения из `config.py`. Ручная передача `articles` и старые маршруты `/v1/prices`, `/v1/prices.xlsx` удалены.

Пример запроса:

```json
{
  "store_url": "https://www.ozon.ru/seller/jkeratin/",
  "pvz_url": "https://www.ozon.ru/geo/moskva/442329/"
}
```

POST требует `Authorization: Bearer ...`; токен задаётся переменной окружения `OZON_API_TOKEN`. `MAX_REQUEST_BYTES` ограничивает **входящий JSON-запрос**, но не число товаров и не размер выгрузки.

Если программа не смогла подтвердить конец каталога, API возвращает 503 и не выдаёт частичную выгрузку как полную. В локальном запуске неполный результат виден с предупреждением.

## Ограничения

Ozon может менять HTML и скорость подгрузки, поэтому полнота определяется по границе каталога и отсутствию новых SKU. При устойчивой CAPTCHA скрипт не решает проверку автоматически; доступ повторно проверяется новым Chrome в пределах `CAPTCHA_MAX_ATTEMPTS`. Google Sheets, старые парсеры карточек и тестовые файлы в текущую ветку не входят.

# OzonPrices — обновление цен Ozon одним кликом

Windows EXE запускает обычный Google Chrome, собирает артикулы и конечные цены магазина Ozon и отправляет их напрямую в Google Таблицу через сервисный аккаунт. **Apps Script, VPS, Python и VSCode сотруднику не нужны.**

## Google Таблица

- **Название документа:** «Проверка цен».
- **Единственный используемый лист:** «Проверка цен OZON».
- **A:B:** артикул Ozon и конечная цена.
- **D:E:** статус, дата, количество, магазин, ПВЗ и предупреждения.
- **H2:** ссылка на магазин; если пустая — `https://www.ozon.ru/seller/jkeratin/`.
- **H3:** ссылка на ПВЗ; если пустая — `https://www.ozon.ru/geo/moskva/442329/`.
- **G1:G3:** подписи полей; **I1:I3:** ссылки по умолчанию.

Программа не изменяет пользовательские ссылки в H2:H3 и не создаёт других листов. Полный сбор заменяет список A:B. Если каталог неполный, ранее найденные позиции сохраняются только при совпадении магазина и ПВЗ; появится предупреждение, что часть цен может быть неактуальна. При неполном сборе после смены магазина/ПВЗ обновление блокируется.

## Для сотрудников

1. Получить от администратора **закрытый** архив `OzonPrices_JKeratin_PRIVATE.zip`.
2. Распаковать папку `OzonPrices` целиком на Windows с установленным Google Chrome.
3. Дважды нажать `OzonPrices.exe`, дождаться окончания и проверить лист «Проверка цен OZON».

Для выгрузки отдельного Excel (без обновления Google) используйте `EXPORT_EXCEL.bat` внутри **закрытого комплекта**. Excel создаётся в папке `exports`; применяются ссылки по умолчанию.

## Один раз для администратора

1. Убедиться, что **Google Sheets API** включён в проекте Google Cloud и сервисный аккаунт `sheets-server@fresh-forest-436813-i5.iam.gserviceaccount.com` имеет роль **Редактор** только на нужном документе «Проверка цен».
2. Скачать JSON-ключ этого сервисного аккаунта на защищённый компьютер. **Не отправлять ключ в GitHub, ChatGPT или GitHub Actions.**
3. Открыть вкладку **Actions → Build Windows EXE → Run workflow** в ветке `main`. После успешной сборки скачать `OzonPrices-Windows-NO-SECRETS` и распаковать полностью.
4. Рядом с папкой `OzonPrices` будет файл `MAKE_PRIVATE_KIT.bat`. Запустить его, указать локальный путь к ключу и URL Google Таблицы.
5. Полученный `OzonPrices_JKeratin_PRIVATE.zip` передать сотрудникам **только по закрытому корпоративному каналу**.

**Безопасность:** закрытый ZIP содержит извлекаемый приватный JSON-ключ. Любой его обладатель фактически получает права сервисного аккаунта. Используйте отдельный аккаунт с доступом только к этой таблице, ограничивайте распространение и отзывайте ключ при компрометации. Публичный EXE ключей не содержит. Windows EXE не подписан цифровой подписью.

## Для разработчика

- `app/scraper.py` — исходный рабочий парсер Selenium; запуск с видимым окном Chrome.
- `app/main.py` — локальный запуск и необязательная выгрузка Excel.
- `app/google_sheets.py` — Google Sheets API, проверка назначения, чтение H2:H3 и запись результатов.
- `.github/workflows/build-windows.yml` — сборка EXE в GitHub Actions.
- `admin/MAKE_PRIVATE_KIT.ps1` — локальная упаковка секретов, не выполняется на GitHub Actions.
- `tests/` — тесты логики интеграции.

Только для разработчика: `python -m pip install -r app/requirements.txt`, `python -m unittest discover -s tests -v`, `python app/main.py`.

Известное ограничение: парсер иногда выдаёт `complete=False` даже после чтения доступных товаров. Отсутствующие позиции при таком результате нельзя считать недоступными.

# Ozon → Google Таблица: обновление цен одним кликом

Локальная программа для Windows. Открывает **обычный Chrome с окном**, выбирает московский ПВЗ, читает артикулы и конечные цены из основного каталога продавца JKeratin и записывает их в Google Таблицу.

**Нет VPS, локального веб-сервера, фонового агента или необходимости вводить SKU.** Chrome должен быть установлен, компьютер — подключён к интернету. Не закрывайте браузер до окончания проверки.

## Сотруднику: первый запуск (Windows)

1. Скачайте ZIP **именно ветки `feature/storefront-price-prototype`** из GitHub (Code → Download ZIP) и распакуйте всю папку.
2. Установите [Python](https://www.python.org/downloads/windows/) версии 3.10+ и [Google Chrome](https://www.google.com/chrome/), если их ещё нет. При установке Python желательно включить `Add Python to PATH`. В VSCode работать не нужно.
3. Дважды щёлкните **`START.bat`**. Он сам создаст `.venv` и установит Selenium. При первом запуске вставьте **ссылку веб-приложения Apps Script** (`.../exec`) и **ключ загрузки**, полученные от ответственного за таблицу.
4. Программа откроет Chrome, соберёт цены, закроет браузер и запишет результаты в Google Таблицу. В следующий раз достаточно двойного клика на `START.bat`.

Ключ и ссылка сохраняются только на компьютере в `config.local.json`. **Не публикуйте этот файл** и не отправляйте его в общий чат. Если меняете папку программы, перенесите `config.local.json` в новую папку. Если нужно заменить доступ, удалите локальный файл и выполните первый запуск заново.

**Не закрывайте чёрное окно до окончания:** там появятся число товаров, адрес ПВЗ, статус загрузки и возможная ошибка. При диагностике можно передать снимок экрана без ключа.

### Дополнительная выгрузка Excel

Дважды щёлкните **`EXPORT_EXCEL.bat`**. Программа снова собирает товары и создаёт `exports/ozon_ГГГГ-ММ-ДД_ЧЧ-ММ-СС.xlsx`. В Google Таблицу в этом режиме ничего не отправляется. При неподтверждённой полноте к имени файла добавляется `_НЕПОЛНЫЙ`.

## Ответственному: однократное подключение Google Таблицы

1. Создайте или откройте нужную Google Таблицу под аккаунтом владельца.
2. Откройте **Расширения → Apps Script** и вставьте в редактор содержимое [`google_sheets/Code.gs`](google_sheets/Code.gs). Сохраните проект.
3. Выберите функцию **`setupConnection`**, нажмите **Выполнить**, разрешите доступ к таблице. Откройте **Журнал выполнения**: он покажет секретный ключ загрузки. Храните его у ответственного.
4. Нажмите **Развернуть → Новое развертывание → Веб-приложение**. «Выполнять от имени»: **Меня**. «Доступ»: **Все (Anyone)**. Разверните, подтвердите запрашиваемые разрешения, скопируйте **URL веб-приложения** с окончанием `/exec` (не `/dev`).
5. Передайте сотруднику две строки **без публикации в интернете**: URL веб-приложения и ключ загрузки. Таблицу сотруднику отдельно расшаривать не нужно: запись выполняется от имени владельца Apps Script.

**Безопасность:** публичный URL принимает загрузку только с длинным секретным ключом; не делитесь ключом с посторонними. Если ключ раскрыт, поменяйте свойство `UPLOAD_TOKEN` в настройках Apps Script и обновите `config.local.json` у сотрудников. В некоторых корпоративных аккаунтах публикация «Все» запрещена администратором Google Workspace — тогда понадобится другая схема авторизации.

Если меняете код `Code.gs` после публикации, создайте **новую версию развертывания** через «Управление развертываниями» (обычное сохранение кода не обновляет опубликованную версию).

## Что будет в Google Таблице

- **«Цены Ozon»** — только когда парсер подтвердил окончание основного каталога.
- **«Цены Ozon (неполные)»** — если товары прочитаны, но конец каталога не подтверждён. Этот результат полезен для проверки цен, но **не перезаписывает** предыдущий полный сбор.
- Данные — колонки **A: Артикул товара** и **B: Конечная цена**, уникальные артикулы отсортированы. Справа в **D:E** — время сбора, ПВЗ, количество и статус.
- Остальные листы Google Таблицы программа не изменяет.

При ограничении доступа Ozon или ошибке Chrome программа завершится с сообщением, а таблица останется без изменений.

## Для разработчика

```bash
python -m pip install -r app/requirements.txt
python app/main.py              # Chrome с окном + Google Таблица
python app/main.py --excel-only # Chrome с окном + локальный Excel
```

Адрес магазина и ПВЗ и настройки ожидания — в `app/config.py`. Данные товаров берутся только из `#contentScrollPaginator`, без переходов в карточки и блок рекомендаций. Оzon может менять разметку/задержки; **неполный** результат отделяется от полного, отсутствующие артикулы не следует считать недоступными.

Никаких фоновых задач, расписания обновлений, HTTP API и сервера в этой версии нет.

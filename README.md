# OzonPrices — проверка цен Ozon

Локальное приложение Windows с полями для магазина и ПВЗ. Сотрудник нажимает «Проверить цены и отправить», программа открывает Chrome, собирает цены, по желанию сохраняет Excel и записывает их в Google Таблицу.

## Установка и запуск на Windows

1. Скачать проект, распаковать в папку, которую не планируется перемещать.
2. Дважды нажать **УСТАНОВКА.bat** (один раз). Файл создаёт `.venv` и устанавливает библиотеки только внутрь него; глобальные библиотеки не изменяются.
3. Дважды нажать **ЗАПУСК.bat** для запуска программы.
4. Ввести ссылки магазина/ПВЗ или оставить пустыми. Нажать кнопку. В окне отображается ход сбора и результат.

Файлы `service-account.json` и `config.local.json` необходимы для текущего подключения Google API. Размещаются в корне проекта, не публикуются в GitHub. **Не распространяйте закрытый JSON-ключ среди сотрудников без отдельного решения по безопасности.**

**По умолчанию:** магазин `https://www.ozon.ru/seller/jkeratin/`, ПВЗ `https://www.ozon.ru/geo/moskva/442329/`. Если поле пустое, используется соответствующее значение по умолчанию.


## Google Таблица

Программа изменяет **только A:B** выбранного листа. Колонки **C и дальше**, другие листы, пользовательские формулы и оформление вне A:B не трогаются. Старый технический блок в D:E новая версия больше не создаёт и не очищает автоматически. Если нужно, администратор может очистить прежние значения D:E вручную.

A — артикул, B — конечная цена. Каждый новый успешный сбор заменяет **только содержимое A:B**, включая старые позиции, которых не было в новом результате. Это не доказывает отсутствие товара на Ozon: сайт может показать не все товары за один проход.

## Важно

Если на странице Ozon ограничения или капча, завершение может быть неуспешным. При ошибке программа показывает её в своём окне. Сохранение Excel отмечается флажком и происходит перед записью в Google.

Разработка и тесты: `python -m unittest discover -s tests -v`.

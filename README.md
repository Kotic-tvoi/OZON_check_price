# OzonPrices — управление полностью из Google Таблицы

**Сотрудники ничего не скачивают и не устанавливают.** Все действия выполняются на листе **«Проверка цен OZON»** Google Таблицы **«Проверка цен»**. На одном выделенном компьютере с Windows один раз настраивается постоянно работающий агент Python, который только ожидает запрос из таблицы.

## Интерфейс листа

| Ячейки | Назначение |
| --- | --- |
| E2 | Флажок **«Запустить проверку»** — поставьте галочку, чтобы запросить сбор |
| H2 | Ссылка на магазин Ozon; пусто = `https://www.ozon.ru/seller/jkeratin/` |
| H3 | Ссылка на ПВЗ; пусто = `https://www.ozon.ru/geo/moskva/442329/` |
| A:B | Артикул и конечная цена |
| D3:E10 | Статус, время, число товаров, фактический магазин и ПВЗ |
| G:I | Подписи и настройки |

Через 0–10 секунд после установки галочки запущенный агент сбрасывает её, показывает «В работе», открывает обычный Chrome, собирает цены и записывает результат в **этот же лист**. Он не открывает карточки товаров по отдельности. При ошибке показывает «Ошибка» и описание в E7.

**Важно:** компьютер с агентом должен быть включён, пользователь Windows — войти в систему, агент — запущен. Google Apps Script, VPS, публичные порты и GitHub Actions не нужны для ежедневных проверок.

## Настройка один раз на выделенном ПК

1. Установите Python 3.10+ с сайта python.org и Google Chrome.
2. Скачайте исходники `main` из GitHub (Code → Download ZIP), распакуйте в постоянную папку на ПК (например, `C:\OzonPriceAgent`).
3. Сервисному аккаунту `sheets-server@fresh-forest-436813-i5.iam.gserviceaccount.com` предоставьте **Редактор** только на документ **«Проверка цен»**. Убедитесь, что Google Sheets API включён в его проекте Google Cloud.
4. В корень папки программы (рядом с `АГЕНТ_СТАРТ.bat`) положите существующий JSON-ключ сервисного аккаунта и переименуйте **локальную копию** в `service-account.json`. Не коммитьте, не выкладывайте и никому не пересылайте ключ.
5. В корне создайте файл `config.local.json` с содержимым: `{"spreadsheet_id": "ID_ИЗ_ССЫЛКИ_НА_ТАБЛИЦУ"}`. ID — строка из адреса Google Таблицы между `/d/` и `/edit`, без самой ссылки.
6. Дважды щёлкните `АГЕНТ_СТАРТ.bat`. Он создаст `.venv`, поставит зависимости внутрь этого окружения, откроет лист, добавит флажок и подписи. Оставьте окно агента открытым.

Затем откройте Google Таблицу, оставьте ссылки H2/H3 пустыми и поставьте галочку E2. После теста можете менять магазин или ПВЗ прямо в таблице.

**Безопасность:** JSON-ключ хранится только на выделенном ПК, не распространяется среди сотрудников. Сервисному аккаунту не давайте лишних доступов. Сохраняйте сам компьютер и ключ защищёнными. При компрометации отзовите ключ через Google Cloud.

## Проверка и ошибки

- Если каталог подтверждён полным, A:B полностью обновляются.
- Если каталог неполный и магазин/ПВЗ не менялись, новые цены дополняют старые артикулы; E3 покажет «Неполный каталог». Старые цены могут быть неактуальны.
- Если каталог неполный и магазин/ПВЗ изменились, программа не смешивает старые и новые товары, показывает ошибку в E7.
- Если Ozon блокирует Chrome, агент пишет ошибку и остаётся готовым к следующему запросу.

## Для разработчика

`app/agent.py` — фоновый локальный агент, `app/scraper.py` — Selenium, `app/google_sheets.py` — Google Sheets API.

Обычный старый запуск `python app/main.py` доступен для диагностики; `python app/main.py --excel-only` дополнительно сохраняет Excel в `exports/`. В повседневной работе эти команды не нужны. GitHub Actions / EXE — необязательная старая ветка доставки, использовать её не требуется.

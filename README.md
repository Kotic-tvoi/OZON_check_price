# Ozon Price Reader → Google Таблицы

**Только сбор цен; никакого изменения товаров или цен в Ozon.** Python 3.10+, Selenium + Chrome. Сервер не хранит базу данных, цены или историю. Один ПВЗ применяется ко всем SKU в одном API-запросе. JSON — основной формат, Excel доступен отдельно.

## Google Таблица

Лист `Цены Ozon`:

| A | B | H |
|---|---|---|
| Артикул товара | Конечная цена | H1: Ссылка на ПВЗ Ozon |
| 380181277 | автоматически | H2: https://www.ozon.ru/geo/moskva/442329/ |
| 2624769265 | автоматически | |

Колонок C (тип цены), D (статус) и других дополнительных столбцов скрипт не создаёт. Если товар недоступен либо цена отсутствует, в B пишется «Нет данных»; при CAPTCHA ячейка остаётся пустой. В JSON отсутствие цены по-прежнему кодируется `price: null` со статусом. Поле `price_type` и подсчёт `verified_ozon_card_prices` исключены из JSON. Возвращаем только видимую цену с проверенной карточки товара. Никаких событий записи цен на Ozon нет.

## Установка и локальный тест в VSCode

```bash
python -m pip install -r app/requirements.txt
python app/server.py --check-pvz https://www.ozon.ru/geo/moskva/442329/ --article 380181277 --headed
```

Локальная проверка открывает Chrome, пытается выбрать ПВЗ через кнопку «Сохранить адрес и перейти к покупкам», проверяет адрес в шапке карточки товара и печатает JSON. Для новых ПВЗ сайт может потребовать правки селекторов. Selenium не тестировался на живом Ozon в среде разработки; API-тесты ниже подменяют браузер.

## Запуск HTTP-сервиса

Установите секрет (не коммитьте токен):

PowerShell:
```powershell
$env:OZON_API_TOKEN = 'your-long-random-secret'
python app/server.py
```

Linux:
```bash
export OZON_API_TOKEN='your-long-random-secret'
python app/server.py
```

По умолчанию приложение слушает только `127.0.0.1:8765`. Для Google Apps Script опубликуйте его через защищённый HTTPS reverse proxy (nginx/Caddy). Не открывайте сам HTTP-порт наружу. Рекомендуются ограничение запросов и контроль доступа по Bearer-токену. Браузер запускается по запросу и закрывается после обработки. Одновременно исполняется не более одного задания.

## API

`POST /v1/prices` с заголовком `Authorization: Bearer <OZON_API_TOKEN>`:

```json
{
  "pvz_url": "https://www.ozon.ru/geo/moskva/442329/",
  "articles": ["380181277", "2624769265"]
}
```

`pvz_url` можно опустить — используется московский ПВЗ по умолчанию. Артикулов в HTTP-запросе от 1 до 100. Пример **с условными ценами**:

```json
{
  "read_only": true,
  "pvz_url": "https://www.ozon.ru/geo/moskva/442329/",
  "summary": {"total": 2, "found": 2},
  "results": [
    {"index": 0, "article": "380181277", "price": 1000, "status": "ok"},
    {"index": 1, "article": "2624769265", "price": 1500, "status": "ok"}
  ]
}
```

Другие методы: `POST /v1/pvz/check`, `POST /v1/diagnostics/price` (один SKU, список ценовых кандидатов для ручной сверки), `POST /v1/prices.xlsx` (двухколоночный Excel, формируется в памяти), `GET /health`.

## Подключение к Google Таблице

1. В Google Таблице откройте **Расширения → Apps Script**, вставьте `google_sheets/Code.gs`.
2. Обновите страницу таблицы и выберите **Ozon — цены → Настроить подключение**. Введите HTTPS-адрес Python-сервиса и его API-токен.
3. В колонке **A** укажите SKU, в **H2** — **одну** официальную ссылку на ПВЗ.
4. В меню **Ozon — цены → Проверить ПВЗ** проверьте адрес, затем выберите **Обновить все цены**.
5. При длительной работе используйте пункт меню **Продолжить обновление**. Скрипт делит строки на пакеты по 16 SKU, чтобы снижать вероятность таймаутов Apps Script. Каждый пакет получает один и тот же `pvz_url` из H2. При переходе на другой ПВЗ запускайте новое обновление.

Перед первым запуском Google запросит авторизацию Apps Script. Секрет хранится в свойствах сценария; редакторы сценария могут его прочитать. Поскольку таблица не является базой данных, цены остаются только в ячейках Google Таблицы, а на сервере — только в памяти на время исполнения запроса.

## Быстрый массовый сбор / блокировка Ozon

- `OZON_PRICE_WAIT` — ожидание цены для подтверждённой карточки (4 секунды по умолчанию). При более медленной загрузке установите `OZON_PRICE_WAIT=6`.
- Если Ozon перебросил на `/search/`, цена товаров из рекомендаций **не записывается**, возвращается `unavailable`.
- Если цена не появилась в пределах ожидания: `no_price`, `price: null`; мгновенно повторять запрос не будем.
- При кратковременной странице `Antibot Challenge Page` парсер **не останавливается мгновенно**: каждые 200 мс проверяет, появилась ли полноценная страница. Если готова сразу, паузы нет. Блокировка фиксируется только после тайм-аута ожидания соответствующей страницы.
- Если возникла настоящая CAPTCHA: Chrome закрывается, после короткой паузы **весь пакет** проверяется заново одним новым Chrome. Результаты прерванной попытки выбрасываются, даже если часть цен уже была получена. Есть только один автоматический перезапуск: если CAPTCHA повторяется, возвращаем `blocked` для всего пакета. Уже успешно завершённые предыдущие пакеты сохраняются в Google Таблице; текущий блокированный пакет остаётся для продолжения позже.
- Параллельный запуск пока не включён: на 119 SKU уже была CAPTCHA даже при последовательных пакетах. После успешных локальных тестов можно сравнить 1 и 2 браузера с соблюдением ограничений доступа.
- Пользовательская настройка `--disable-blink-features=AutomationControlled` из исходного проекта включена в `create_driver()`, поскольку локальный тест с ней прошёл успешно.
- CAPTCHA автоматически не решается. Автоматический повтор только один, чтобы не создавать бесконечную очередь запросов при ограничении доступа.

### Локальный массовый тест в Git Bash

```bash
python tests/local_batch_benchmark.py --batch 16 --limit 32 --headed
```

Для полного теста 119 SKU уберите `--limit 32`. Для другой ссылки на ПВЗ добавьте `--pvz https://www.ozon.ru/geo/moskva/442329/`. Результаты печатаются только в терминал, без базы или файлов цен.

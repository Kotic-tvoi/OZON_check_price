# Ozon — сбор цен со страницы магазина

Парсер **только читает** цены из основного каталога продавца Ozon (`#contentScrollPaginator`). Карточки товаров по отдельности не открывает, блок «Возможно, вам понравится» не собирает, цены не меняет, базу данных не использует.

## Настройки

Все стандартные параметры вынесены в **`app/config.py`**:

| Параметр | Назначение |
|---|---|
| `DEFAULT_STORE` / `DEFAULT_PVZ` | Магазин и ПВЗ по умолчанию |
| `LOAD_TIMEOUT` | Максимальное ожидание новых карточек (2 с) |
| `SCROLL_POLL_INTERVAL` | Частота проверки новых карточек (0,1 с) |
| `IDLE_LIMIT` / `MAX_SCROLLS` | Ограничения прокрутки |
| `CAPTCHA_MAX_ATTEMPTS` | **Общее число запусков** браузера при CAPTCHA, включая первый (2 = один повтор) |
| `PVZ_*` / `STORE_*` | Ожидания выбора ПВЗ и страницы магазина |

Для 5 общих попыток после обнаружения CAPTCHA укажите `CAPTCHA_MAX_ATTEMPTS = 5`. При блокировке Chrome закрывается и весь магазин собирается заново в новой сессии. Внешний сервис не хранит историю.

## Локальный запуск

```bash
python -m pip install -r app/requirements.txt
python app/main.py --headed
```

Другой магазин и ПВЗ без изменения конфигурации:

```bash
python app/main.py --headed --store "https://www.ozon.ru/seller/another-seller/" --pvz "https://www.ozon.ru/geo/moskva/442329/"
```

Дополнительный JSON: `--json prices.json`. Excel в двух колонках: `--xlsx ozon_prices.xlsx`.
Артикулы в Excel записываются текстом, цены — числами, при отсутствии цены выводится «Нет данных».
Excel создаётся только при указании `--xlsx`, без запуска HTTP-сервера. Если полнота каталога не подтверждена, файл содержит только найденные товары и выводится предупреждение.
Настройки можно переопределять при запуске, например:

```bash
python app/main.py --headed --load-timeout 3 --max-attempts 5
```

Проверяйте итог `конец каталога подтверждён: True/False`: при `False` полный каталог не гарантирован; отсутствующий артикул нельзя автоматически считать недоступным.

## HTTP API (после локальной проверки)

```bash
export OZON_API_TOKEN='your-long-random-secret'
python app/server.py
```

`GET /health` проверяет доступность. `POST /v1/catalog` принимает `store_url` и `pvz_url` и возвращает товары магазина. `POST /v1/prices` дополнительно принимает `articles` и возвращает цены нужных SKU. `POST /v1/prices.xlsx` предоставляет дополнительную двухколоночную выгрузку. Все POST-запросы требуют `Authorization: Bearer ...`. Без подтверждения полноты каталога API выдаёт ошибку 503, не выдавая неполный результат как достоверный.

## Замечания

- Страница ПВЗ проверяется перед сбором, каталог считывается только внутри основной ленты.
- Окончание каталога определяется по границе и отсутствию новых SKU; при изменениях на Ozon селекторы могут потребовать обновления.
- Временная страница `Antibot` не всегда означает постоянную блокировку; реальная CAPTCHA автоматически не решается.
- Серверные настройки и токен хранятся в переменных окружения, а не в `config.py`.
- Google Таблицы и тестовые файлы не входят в эту ветку. Сохранённые предыдущие версии доступны в отдельных ветках.

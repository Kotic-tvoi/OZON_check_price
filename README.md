# OzonPrices — проверка цен Ozon

Локальная программа Windows для проверки конечных цен Ozon. Пользователь при необходимости указывает магазин и ПВЗ и нажимает «Проверить цены и отправить». Программа открывает Chrome, собирает цены, по желанию сохраняет Excel и передаёт результаты в Google Таблицу.

## Запуск на Windows

1. Скачать проект и распаковать в постоянную папку. Нужны установленные Python 3 и Google Chrome.
2. **Дважды нажать `ЗАПУСК_БЕЗ_КОНСОЛИ.vbs`** — обычный запуск без чёрного окна. Для первой установки и диагностики можно открыть `ЗАПУСК.bat`, чтобы видеть ошибки. Других команд вводить не требуется.
3. При первом запуске скрипт автоматически создаёт `.venv` и ставит зависимости **только в виртуальное окружение**. При следующих запусках проверяет доступность библиотек и сразу открывает интерфейс.
4. Ввести ссылки магазина и ПВЗ или оставить поля пустыми: по умолчанию используются магазин JKeratin и московский ПВЗ.
5. Нажать кнопку. Программа покажет итоговое сообщение «Готово. Выгружены цены N товаров». Подробные шаги прокрутки не выводятся.

Для подключения Google API рядом с `ЗАПУСК.bat` необходимы `service-account.json` и `config.local.json`. Это закрытые файлы администратора. **Не загружайте их в GitHub и не распространяйте JSON-ключ публично.**

## Google Таблица

Документ «Проверка цен», лист «Проверка цен OZON»: программа обновляет **только колонки A и B** (артикул и конечная цена). Столбцы **C и дальше** не очищаются и не изменяются. Старые служебные данные в D:E автоматически не очищаются; при необходимости удалить их можно вручную.

При новом сборе A:B заменяются текущими данными; отсутствие артикула в результатах не гарантирует отсутствие товара в Ozon.

## Для разработчика

Исходники программы находятся в `app/`. Файл `.gitignore` в корне защищает локальные ключи, таблицы и `.venv` от случайной публикации. Его не следует перемещать в `app/`, так как тогда перестанут действовать исключения для секретных файлов в корне. В Проводнике Windows этот технический файл можно скрыть без удаления: `attrib +h .gitignore`.

Столбец A заполняется числовыми значениями артикулов. Программа не меняет форматирование ни одного столбца и не затрагивает столбцы C и далее.

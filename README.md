# Ozon Price Reader — два Chrome параллельно (тестовая версия)

Только чтение цен с Ozon, без изменения цен и без базы данных. HTTP API принимает **один URL ПВЗ** и **до 100 артикулов**. По умолчанию два независимых Chrome запускаются одновременно и делят список на две последовательные половины; в каждой сессии свой браузер, свой выбор ПВЗ, затем все SKU половины в одной вкладке. В конце результаты объединяются в исходном порядке в **один JSON-ответ**. Каждую цену берём с карточки заданного артикула; результаты перенаправлений на похожие товары не учитываются.

Рабочую версию с пакетами по 16 SKU сохранили в ветке [`archive/batched-16-working-2026-10-08`](https://github.com/Kotic-tvoi/OZON_check_price/tree/archive/batched-16-working-2026-10-08). Вариант **один Chrome на 100 SKU** оставили в [`feature/single-browser-100-sku`](https://github.com/Kotic-tvoi/OZON_check_price/tree/feature/single-browser-100-sku).

## Локальная проверка — Git Bash

```bash
python -m pip install -r app/requirements.txt
python tests/local_dual_session.py --limit 100 --headed
```

В корне проекта нужен `SKU_Ozon.txt` со списком артикулов по одному на строку. **Для объективного сравнения** запустите тот же список одним браузером:

```bash
python tests/local_dual_session.py --limit 100 --headed --workers 1
```

Сделайте паузу между большими тестами, если Ozon начал ограничивать доступ. Сравните время и количество блокировок; два браузера с одного IP могут вызвать CAPTCHA чаще, несмотря на более быструю обработку. Для оставшихся 19 из списка 119 используйте `--offset 100 --limit 19`. По умолчанию `--workers 2`.

## Выбор ПВЗ и CAPTCHA

- На странице ПВЗ парсер проверяет **одновременно** наличие адреса в заголовке и готовой кнопки; ожидание прерывается сразу после появления обоих (поллинг 150 мс). Никакой фиксированной паузы после загрузки нет.
- После нажатия «Сохранить адрес» проверяется реакция интерфейса (до 1,2 секунды за попытку, до двух нажатий при отсутствии реакции). Полного перехода на главную страницу больше не ждём. Первый товар открывается через `driver.get()` **в той же вкладке**, а реальный выбранный ПВЗ проверяется в шапке прежде, чем вернуть цену или «Нет данных».
- Промежуточный `Antibot Challenge Page` не считается немедленной блокировкой. Если Ozon не пропускает дальше в пределах установленного ожидания, возвращается ошибка; никакие цены не подставляются.
- **Каждая половина** при CAPTCHA или невозможности подтвердить ПВЗ перезапускается **полностью**, максимум 5 попыток и без дополнительного `sleep`. Уже завершившаяся другая половина не проверяется снова. Если одна половина так и не прошла, в общем JSON остаются диагностические статусы; Google Таблица **не перезаписывает** результаты неудачного общего запроса.
- После многократного ограничения доступа тест лучше прекратить, а не запускать серию новых запросов. Автоматического решения CAPTCHA нет.

## API для Google Таблиц

```bash
export OZON_API_TOKEN='your-long-random-secret'
python app/server.py
```

Локальный адрес: `127.0.0.1:8765`. Для Apps Script понадобится HTTPS reverse proxy. Пример JSON-запроса:

```json
{
  "pvz_url": "https://www.ozon.ru/geo/moskva/442329/",
  "articles": ["380181277", "1648595002"]
}
```

`POST /v1/prices` возвращает `results` с `index`, `article`, `price` и `status`. История цен не сохраняется. `POST /v1/prices.xlsx` — дополнительная выгрузка Excel из памяти. В Google Таблице столбец **A** — артикул, **B** — конечная цена или «Нет данных», **H2** — одна ссылка на ПВЗ. Тип цены не определяем. Код Google Apps Script находится в `google_sheets/Code.gs`. В одном HTTP-запросе до 100 SKU, без пакетов по 16.

## Автоматические проверки

```bash
python -m unittest discover -s tests -v
node tests/test_google_sheets.cjs
```

Тесты Selenium используют имитацию браузера, а не настоящий сайт. Стабильность на Ozon и фактический выигрыш от параллельного запуска проверяются локально в видимом Chrome.
